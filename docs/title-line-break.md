# 제목·본문 줄 나누기 규칙

앱의 모든 제목과 본문은 이 규칙으로 줄을 나눕니다 (2026-11-13).
- 제목: `text-display` 28, `text-title` 22
- 본문: `text-body` 18, `text-label` 15, `text-small` 14, `text-button` 18
사장님이 한눈에 읽도록, 글자 수가 아니라 **뜻의 덩어리**로 나눕니다.

- 코드: 규칙은 [`mobile/src/lib/titleBreak.ts`](../mobile/src/lib/titleBreak.ts), 적용은 [`mobile/src/components/ui/Text.tsx`](../mobile/src/components/ui/Text.tsx) (모든 글자가 쓰는 공통 `Text`).
- 화면 글을 새로 쓸 때 줄 바꿈(`\n`)을 넣지 않아도 됩니다. 넣어도 쓰지 않고 이 규칙으로 다시 나눕니다.
- **이 규칙을 쓰지 않는 글**
  - 80자가 넘는 글 (손님 리뷰, 답글 초안처럼 앱이 쓰지 않은 글): 적어 둔 줄 바꿈을 그대로 씁니다.
  - 줄 수를 정해 둔 글 (`numberOfLines`)

## 규칙

1. **한 줄에 들어가면 한 줄로 둡니다.**
   예) "휴대폰 번호를 적어 주세요"
2. **띄어쓰기 자리에서만 나눕니다.** 단어 가운데서는 나누지 않습니다.
3. **함께 읽어야 하는 말은 한 덩어리로 묶어서, 그 사이에서는 나누지 않습니다.**

   | 덩어리 | 예 |
   |---|---|
   | 서술어 + 보조용언 | 확인해 주세요, 바꿔 드릴게요, 보내지 않아요, 열고 있어요, 받을 수 있어요 |
   | 관형어 + 꾸밈받는 말 | 온 숫자, 할 일이, 바쁜 시간엔, 늦었다는 리뷰예요 |
   | 관형사 + 명사 | 이번 주말, 다른 가게, 오늘 할 일이 |
   | 부사 + 뒷말 | 다시 할까요, 조용히 할게요, 먼저 보여 드려요 |
   | 조사 없는 수량 + 뒷말 | 1개 남았어요, 3시에 |
4. **줄을 바꿔야 하면 나눌 자리를 이 순서로 고릅니다.**
   1. 문장이 끝나는 자리(`.` `?` `!`) 뒤
      "인터넷이 끊겼어요. / 뒤로 가서 다시 연결해 주세요"
   2. **서술어(마지막 덩어리) 앞.** 서술어를 아랫줄로 내리고 윗줄은 꽉 채웁니다.
      "문자로 온 숫자 6자리를 / 입력해주세요."
   3. 조사나 쉼표로 끝나는 덩어리 뒤. 그런 자리가 여럿이면 윗줄을 가장 많이 채우는 자리를 고릅니다.
   4. 그래도 없으면 윗줄에 들어가는 가장 뒤 덩어리 뒤
   5. 아랫줄도 넘치면, 남은 글에 같은 규칙을 다시 씁니다.

## 예

| 제목 | 놓인 자리 | 나뉜 모양 |
|---|---|---|
| 문자로 온 숫자 6자리를 입력해주세요. | 화면 폭 (28) | 문자로 온 숫자 6자리를 / 입력해주세요. |
| 네이버 플레이스를 연결해 주세요 | 도나 그림 옆 (28) | 네이버 플레이스를 / 연결해 주세요 |
| 이번 주말 포스터를 만들어 드릴게요 | 카드 안 (22) | 이번 주말 포스터를 / 만들어 드릴게요 |
| 배달이 늦었다는 리뷰예요 | 좁은 카드 (22) | 배달이 / 늦었다는 리뷰예요 |
| 바쁜 시간엔 조용히 할게요 | 좁은 자리 (28) | 바쁜 시간엔 / 조용히 할게요 |
| 휴대폰 번호를 적어 주세요 | 화면 폭 (28) | 한 줄 |
| (본문) 도나를 쓰려면 네이버 동의가 필요해요. 다시 하기를 누르면 네이버 화면이 다시 열려요 | 화면 폭 (18) | 도나를 쓰려면 네이버 동의가 필요해요. / 다시 하기를 누르면 네이버 화면이 / 다시 열려요 |
| (본문) 지금은 도나 알림이 없어요 | 잠금 화면 (18) | 한 줄 |

## 어떻게 동작하나

1. 공통 `Text`가 위 글꼴이고 글 하나짜리(80자 이하)면, 적어 둔 줄 바꿈을 빼고 **한 줄로 먼저 그립니다.**
2. 그린 높이가 한 줄이면 그대로 둡니다.
3. 넘쳐서 두 줄 이상이 되면, 그때 글이 놓인 실제 폭을 재요. 그 폭으로 위 규칙을 써서 줄 바꿈을 넣고 다시 그립니다. 그래서 화면 폭, 카드 안, 그림 옆처럼 자리가 달라도 그 자리에 맞게 나뉩니다. 화면 폭이 바뀌면 다시 따집니다.
4. 글자 폭은 굵은 Noto Sans KR을 웹에서 잰 값(글자 크기 대비)으로 어림합니다. 본문 글꼴(보통·중간 굵기)도 한글 폭은 0.92로 같고, 숫자·문장부호는 굵은 글꼴보다 조금 좁아서 넘치지 않습니다. 어림이 조금 틀려도 넘치지 않게 폭을 2% 덜 씁니다.

   | 한글 | 띄어쓰기 | 숫자 | 영문 | 쉼표·마침표 |
   |---|---|---|---|---|
   | 0.92 | 0.28 | 0.59 | 0.62 | 0.33 |

## 손볼 때

- 덩어리를 잘못 묶는 말이 있으면 `titleBreak.ts`의 목록에 더합니다.
  - `MODIFIER_WORDS`: 관형사·부사
  - `ADNOMINAL_END`: 관형어 끝
  - `AUX`: 보조용언
  - `PARTICLE_END`: 조사
- 글 안에 다른 꾸밈(굵은 글씨 일부, 밑줄 등)이 섞인 제목은 글 하나가 아니라서 이 규칙을 쓰지 않습니다. 예: 시작 화면 "매장 운영, 도나가 먼저 챙겨요"
