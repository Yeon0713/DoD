# 아직 못 만든 것과 필요한 기능

도나 v0.2.0 새 앱(`donna-voice/`)을 만들면서 **구현하기 애매했던 것**을 모았습니다. 지금은 목업이거나 빠져 있고, 사장님이 실제로 쓰려면 필요한 것들입니다.

> 기준: 2026-11-15

읽는 법: "지금"은 앱이 현재 어떻게 동작하는지, "필요한 것"은 사장님이 쓰려면 무엇이 있어야 하는지입니다.

---

## 1. 음성

| 항목 | 지금 | 필요한 것 |
|---|---|---|
| 휴대폰·태블릿 앱에서 듣기와 읽기 | 웹(브라우저)에서만 됩니다. 앱으로 설치하면 마이크가 "이 기기는 말을 못 들어요"로 나옵니다 | 앱용 STT와 TTS. `src/lib/voice.ts` 한 파일만 바꾸면 화면 코드는 그대로입니다 |
| 실제 마이크로 말해 보기 | **확인하지 못했습니다.** 개발 환경의 브라우저에는 마이크가 없어서, 칩을 누르거나 개발용 길(`__donna.say('...')`)로 말을 넣어 확인했습니다 | 실제 주방 소음 속에서 써 보기 |
| 도나가 말하는 중에 끼어들기 | 도나가 읽는 동안에는 듣지 않습니다. 스피커 소리가 마이크로 다시 들어오기 때문입니다. 끼어들려면 칩을 눌러야 합니다 | 도나 목소리만 걸러 내는 처리(에코 제거). 손을 못 쓰는 사장님에게는 꼭 필요합니다 |
| 화면이 꺼지지 않게 하기 | 없습니다 | 늘 듣고 있으려면 화면이 꺼지면 안 됩니다. 앱이 켜져 있는 동안 화면을 켜 두는 설정이 필요합니다 |
| 앱이 뒤로 가 있을 때 듣기 | 없습니다 | 다른 앱을 보고 있을 때도 들을지 정해야 합니다. 지금 약속은 "앱을 켜 둔 동안에만 들어요"입니다 |
| 호출어 | **"도나야"** (2026-11-16 결정). 받아쓴 글자가 "도나야"로 시작하는지를 앱이 봅니다. 부르지 않은 말은 화면에 적지 않고 서버로 보내지 않습니다 | 지금은 브라우저가 모든 말을 받아쓴 뒤에 글자로 거릅니다. 앱에서는 기기 안에서 호출어만 듣는 처리(빅스비처럼)가 있어야 배터리와 사생활 걱정이 없습니다. "도나야"가 주방 소음 속에서 얼마나 잘 잡히는지도 써 봐야 합니다 |
| 도나의 목소리 | 기기에 들어 있는 기본 목소리 | 도나다운 목소리를 정해야 합니다 |

## 2. 화면

| 항목 | 지금 | 필요한 것 |
|---|---|---|
| 답을 기다리는 동안 | 듣기 알약에 받아쓴 말이 그대로 남아 있습니다 | Figma에 상태가 없습니다. 1초를 넘기면 "찾아보고 있어요"를 보여 줄지 정해야 합니다 |
| 브리핑 준비가 안 끝났을 때의 홈 | 목업은 늘 준비가 끝나 있습니다 | 출근 한 시간 전보다 일찍 켰을 때의 화면 |
| 허락을 거절했을 때의 3단계 | 아쉬운 리뷰를 줄여서 알려 주기만 합니다 (Figma에 없어 임시로 만든 것) | 사장님이 직접 답하는 흐름. 도나가 초안을 써 주고 말로 고칠 수 있어야 합니다 |
| 작은 휴대폰(세로 640 안팎)에서 도나의 말 | 내용이 길면 도나가 읽는 만큼 화면이 저절로 내려갑니다. 이때 맨 위의 도나 말(첫마디와 지금 읽는 문장)이 화면 밖으로 올라갑니다 | 도나의 말은 위에 붙여 두고 카드만 내려가게 하기 |
| 마이크를 켜지 않고 쓰기 | 칩을 눌러서 씁니다. 듣기 알약은 "마이크가 꺼져 있어요"로 남고, 누르면 켜는 화면으로 갑니다 | 칩에 없는 말은 할 수 없습니다. 글자로 묻는 칸을 둘지 정해야 합니다 |
| 태블릿 화면 | 규칙(600 미만, 600 ~ 899, 900 이상)만 정해 구현했습니다. Figma에는 태블릿 그림이 없습니다 | Figma에 태블릿 세로와 가로 화면을 그려 확정하기 |
| 시작 화면(E-01)의 소개 글 | Figma에는 예전 기능 네 가지가 적혀 있어, v0.2.0이 실제로 하는 일 세 가지로 바꿨습니다 | Figma E-01도 같은 내용으로 고치기 |

## 3. 탭

Figma에 화면이 없어 "사장님이 그 탭에서 알고 싶은 것"에서 출발해 새로 만들었습니다. 데이터는 모두 목업입니다.

| 탭 | 지금 | 필요한 것 |
|---|---|---|
| 일정 (예전 이름: 이번 주) | 달력(이번 주 / 이번 달)과 고른 날 하나 | 날짜는 손으로 눌러 고릅니다. 이 탭은 눈으로 보는 화면이라 말로 고르는 기능은 넣지 않았습니다 |
| 달력의 날짜별 내용 | 이번 주 7일만 Figma 기준 데이터입니다. **그 밖의 날은 규칙으로 만든 값입니다**: 지난 날의 "한 일"은 날짜 숫자로 만든 개수이고, 이번 주 밖의 앞날은 단체 예약 하나와 경기 하나만 넣어 두었습니다 | 실제 기록과 실제 일정. 달을 넘겨 보는 것(지난달, 다음 달)도 없습니다 |
| 달력의 표시 | 일이 잡힌 날(옅은 색), 답글 올리는 날(점) 두 가지 | 쉬는 날도 표시할지 정해야 합니다 |
| 일정의 "브리핑을 듣고 한 일" | 자동으로 적히는 것은 두 가지뿐입니다: 브리핑을 끝까지 들음, 아쉬운 리뷰를 맡김(또는 거절). 어제의 "배달 안내 시간을 10분 늘렸어요"는 보기용 고정 데이터입니다 | 도나가 권한 것(고칠 점, 준비할 것)을 사장님이 실제로 했는지는 앱이 알 수 없습니다. "했어"라고 말하거나 눌러서 적는 길이 필요합니다 |
| 일정의 "아직 남은 것" | 못 들은 브리핑, 답을 기다리는 아쉬운 리뷰, 오늘 남은 일정(행사, 경기, 단체 예약) | 일반 예약도 하나씩 보일지, 지나간 일정을 어떻게 뺄지 정해야 합니다 |
| 지난 일 | 달력에서 지난 날을 눌러야 보입니다. 어제와 지난주를 묶어 보여 주던 것은 볼 것을 줄이려고 뺐습니다 | 실제 기록 저장. "지난주에 뭘 했지"를 한눈에 보는 요약이 필요한지 확인 |
| 예약한 답글 전체 | 달력에서 점이 찍힌 날을 눌러야 보입니다. 전체 목록은 뺐습니다 | 한꺼번에 보고 싶어 하는지 확인 |
| 일정의 "준비할 것" | 비 오는 날, 경기 날의 고정 문장. 단체 예약에는 붙이지 않습니다 (자리 배치 같은 매장 준비는 도나가 말하지 않음, 2026-11-16 결정) | 에이전트가 일정에서 실제로 만들어 내야 합니다. 근거 없는 조언이 나오지 않게 하는 규칙도 필요합니다 |
| 일정의 "잡힌 일" | 행사, 경기, 단체 예약, 비를 고정 데이터로 보여 줍니다. 붐빔 예상(바쁨·보통)은 사장님에게 필요하지 않아 뺐습니다 | 단체 예약을 어디서 받아 올지(네이버 예약, 전화 예약을 사장님이 말로 알려 주기 등)가 정해지지 않았습니다. 사장님이 말로 일정을 더하는 기능("금요일 7시에 단체 열 분 예약 있어")도 필요해 보입니다 |
| 매출 | 어제(또는 오늘 지금까지)와 지난주 같은 요일, 이번 주 막대, 잘 팔린 메뉴 3개 | 실제 매출 데이터 연결. 원가와 이익은 넣지 않았습니다 (필요한지 확인) |
| 매출을 말로 묻기 | 홈에서 "매출 어때"라고 하면 매출 탭으로 옮기고 한 문장으로 읽어 줍니다 | "지난주 토요일은?", "들깨옹심이 몇 그릇 팔았어?" 같은 자유로운 질문 |
| 다른 탭에서 말로 돌아오기 | **안 됩니다.** 듣는 것은 홈에서만 합니다. 일정, 매출, 설정에서는 메뉴바의 홈을 손으로 눌러야 돌아옵니다 | 손을 못 쓰는 사장님이 말로 매출 탭에 갔다가 돌아올 길이 없습니다. 다른 탭에서도 "홈" 한마디는 들을지 정해야 합니다 |
| 설정 | 소리, 마이크, 아쉬운 리뷰 바로 답하기, 브리핑 준비 시각(보기만), 연결된 곳(보기만), 로그아웃 | 영업시간 바꾸기, 리뷰 플랫폼 연결하고 끊기 |
| 설정을 말로 바꾸기 | 없습니다. 화면에는 "언제든 말로 끌 수 있어요"라고 약속했습니다 | "아쉬운 리뷰 답글 꺼 줘"를 알아듣는 것. 약속한 기능이라 먼저 만들어야 합니다 |

## 4. 백엔드와 데이터

| 항목 | 지금 | 필요한 것 |
|---|---|---|
| 에이전트 | 없습니다. 규칙과 고정 데이터로 답합니다 (`server/app/`) | 인수인계 문서의 F1 ~ F10 |
| 로그인 | 어느 버튼을 눌러도 통과합니다 | 네이버 로그인, 휴대폰 번호 인증, 가게 연결 |
| 리뷰, 예약, 행사, 경기, 날씨 | Figma 화면과 같은 고정 데이터 한 벌 | 실제 수집 |
| 답글 올리기 | 실제로 올리지 않습니다. 상태만 "올림"으로 바꿉니다 | 플랫폼에 실제로 올리기, 실패했을 때 알리기 |
| 정해진 시각에 도는 작업 | 없습니다. 요청이 올 때마다 브리핑을 새로 만듭니다 | 밤사이 수집, 30분 안에 답하기, 출근 한 시간 전 준비, 예약한 답글 올리기 |
| 개발자 대시보드 | 없습니다. 사장님이 쓰는 것이 아니라 앱에 넣지 않았습니다 | 리뷰 넣기, 시각 옮기기는 `/v1/dev/*`로 할 수 있습니다. 화면이 필요하면 따로 만듭니다 |

## 5. 인수인계 문서에 더한 것

구현하면서 계약에 없던 것이 생겼습니다. [docs/v0.2.0-voice-agent-handoff.md](../../docs/v0.2.0-voice-agent-handoff.md) 16장에 적어 두었습니다.

- 응답 종류 `navigate`: "매출 어때"처럼 다른 탭을 여는 말
- `GET /v1/week`, `GET /v1/sales`: 일정 탭과 매출 탭의 데이터
- `GET /v1/settings`에 가게 이름, 브리핑 준비 시각, 연결된 곳

## 7. 가입부터 탈퇴까지 (2026-11-16)

| 무엇 | 지금 | 필요한 것 |
|---|---|---|
| 휴대폰 번호 가입 | 문자를 보내지 않습니다. 숫자 000000 만 틀린 것으로 봅니다 (이전 앱과 같은 목업) | 문자 인증 |
