# AI 포스터 (인스타 스토리)

포스터 할 일(행사·경기가 있는 날, 행사 없는 주말)에서 **사진을 고르고 → 문구와 느낌을 고르면 → 도나가 인스타 스토리(1080 × 1920) 포스터를 그립니다.**
문구는 CLOVA 가 그날 상황을 보고 추천하고, 그림은 ChatGPT 그림 모델이 그립니다.

## 1. 사장님 화면 (`mobile/src/components/poster/AiPosterScreen.tsx`)
할 일 카드는 도나가 행사·일정을 먼저 보고 필요한 홍보를 챙겨 주는 말투입니다.
- 만들기 전: **"남양 가을 축제에 맞춰 / 초옹장 홍보 준비할게요"** (모바일에서 두 줄, 늘 "맞춰" 뒤에서 줄을 바꿈. 행사 이름이 5자 이하면 요일을 붙여 "토요일 지역 행사에 맞춰", 행사 없는 주말은 "이번 주말에 맞춰". 행사 이름이 9자보다 길면 "지역 행사"처럼, 가게 이름이 6자보다 길면 "우리 가게". 제목의 가게 이름은 브랜드 색(갈색)으로 칠함). 카드 아래 도나: "인스타·가게 홍보용 포스터를 / 만들어 드려요". 그 아래 빈 곳에 넘겨 보는 **그림 도움말 카드 4장**: 가벼운 SVG 그림 + 한 줄 제목 (1 사진을 골라 주세요: 사진 고르기 화면 / 2 로고는 배경을 지워 넣어요: 원본 → 바탕 지운 로고 → "가게 로고 넣기" 줄 / 3 도나가 문구를 골라 드려요: 위 도나와 다른 그림(b3-3, 노트북 앞에서 윙크하며 엄지. 캐릭터 시트에서 잘라 `mobile/assets/donna/b3-3.png` 로 둠)의 도나와 문구 카드 3장 / 4 1분이면 스토리 포스터 완성: 9:16 화면에 문구·날짜·사진·로고가 들어가는 자리). 실제 포스터 그림은 넣지 않습니다. 모바일 폭(375) 기준으로 한 화면에 들어가고, 도나 한마디와 "포스터 만들기" 버튼 사이 빈 곳의 세로 가운데에 놓여 위아래 간격이 같습니다, 카드 아래 ‹ · 점 · › 줄로 좌우로 넘깁니다 (`mobile/src/components/task/PosterGuide.tsx`, 그림 `PosterGuideArt.tsx`). 홈 제목: "도나가 가게 홍보를 준비할게요"
- 만들어 둔 뒤(올리는 날): **"남양 가을 축제 포스터를 / 다 만들어 뒀어요"** + 만든 포스터 그림. 도나: "이제 올리기만 하면 돼요", 버튼 "인스타에 올리기". 홈 제목: "도나가 홍보 포스터를 다 만들어 뒀어요"

카드 제목의 행사 이름은 **실제 이름**입니다. 달력 API(`GET /api/calendar`)가 `names`(행사·경기 id → 이름)를 같이 보내고, 14자보다 길거나 목업이면 "지역 행사"처럼 줄여 씁니다. 경기는 "축구 경기"처럼 종목만 씁니다. 주말 내내 하는 행사는 날짜 줄이 "10월 10일~11일 주말"입니다.

날짜 줄 아이콘은 행사·경기 종류 그림 11개입니다 (Figma `00 · 에셋` 페이지 › `00f · 포스터 행사·경기 아이콘`, 앱 `mobile/assets/icons/occasion/`, 고르는 법 `mobile/src/components/ui/occasion.ts`).
- 행사: 이름에 "대학" → 대학 축제, "마라톤" → 마라톤, "축제" → 지역 축제, 그 밖 → 일반 행사
- 경기: 축구 / 야구 / 농구 / 배구 / e스포츠, 그 밖 → 일반 경기
- 행사·경기 없는 주말 → 주말 홍보
- 같은 그림을 이번 주 미리보기 카드의 행사 줄, 이번 주 › 행사 화면 맨 위에도 씁니다.

서버를 쓸 때 `/poster/<할 일 id>` 가 이 화면입니다. 목업(`EXPO_PUBLIC_USE_MOCK=true`)일 때는 예전처럼 앱이 그려 만드는 포스터(`PosterScreens.tsx`)입니다.

1. **어떤 사진을 넣을까요?**
   - 맨 위 **가게 로고 넣기**: 줄을 누르면 넣을지 켜고 끕니다. **로고 그림을 누르면** 휴대폰에서 다른 로고를 골라 바꿉니다 (마우스를 올리거나 누르고 있으면 연필 표시가 뜸). 로고가 없으면 "가게 로고 올리기". 올린 로고는 서버가 배경을 지워 두고 네이버에서 찾은 로고보다 앞섭니다 ([reservations-and-store-photos.md](reservations-and-store-photos.md)).
   - "3장까지 고를 수 있어요" 아래 한 줄 **+ 사진 올리기**: 사장님이 휴대폰 사진을 올립니다. 올린 사진은 목록 맨 앞에 붙습니다.
   - 네이버 매장 사진·메뉴 사진 중 3장까지 고릅니다.
2. **어떤 포스터를 만들까요?**
   - 그날 상황: "10월 10일(토) 남양 가을 축제, 가게에서 0.3km", "낮 9.5도, 쌀쌀해요"
   - 도나가 고른 문구 3개 (CLOVA). 마음에 안 들면 **직접 쓸게요**.
   - 포스터 느낌: 음식 사진을 크게 / 깔끔한 디자인 / 행사·응원 분위기 / 따뜻한 손글씨
   - 더 넣고 싶은 말 (예: 응원하는 팀을 리뷰에 남겨 주시면 쿠폰을 문자로 보내 드려요)
3. **도나가 포스터를 그리고 있어요**
   - 30초~2분 걸립니다. 서버가 뒤에서 그리므로 다른 화면에 다녀와도 이어서 기다립니다.
4. **포스터 미리 보기**
   - 바로 올릴 때(실행 알림): **인스타 스토리에 올리기**, 휴대폰에 저장하기, 다시 만들기.
   - 승인 알림(올리는 날 전)에서 만들었을 때: **이대로 만들어 두기**. 올릴 날 홈 카드에 그 그림이 보이고, 누르면 바로 올립니다.

## 2. 문구 추천 (`server/app/poster_ai/situation.py`, `ment.py`)
- **상황**: 할 일 id(`POSTER:<근거>:<날짜>`)로 그날 행사(이름, 거리)·경기(이름, 시각), 날씨(낮 최고·최저, 비), 계절(달력 SEASON), 가게 메뉴를 모읍니다.
  - 날씨 표시: 30도 이상 **더워요**, 10도 아래 **쌀쌀해요**, 비 1mm 이상 **비 소식**(아주 추우면 **눈 소식**), 6/19~7/27 **장마철**.
- **CLOVA** 에 상황과 메뉴를 주고 문구 3개를 JSON 으로 받습니다.
  - 행사 날: 행사 이름을 넣은 문구
  - 경기 날: 응원 이벤트 문구
  - 날씨·계절: "오늘은 이 메뉴 어떠세요?"
  - 메뉴는 목록에 있는 이름만 받고, 너무 긴 문구는 뺍니다. 가격·할인은 지어내지 말라고 합니다.
- CLOVA 키가 없거나 답이 이상하면 정해 둔 문장으로 만듭니다 (화면 제목이 "이런 문구는 어떠세요?"로 바뀜). 개발자 대시보드 AI 비용에는 **포스터 멘트 추천**으로 남습니다.

## 3. 그림 만들기 (`server/app/poster_ai/prompt.py`, `image_engine.py`, `jobs.py`)
- **프롬프트**: 상황, 고른 느낌, 첨부 그림의 역할을 적습니다.
  - 그림 1은 로고: 그대로 쓰고 다시 그리지 말 것
  - 그다음은 메뉴 사진: 같은 음식으로 그릴 것
  - 큰 글자·작은 글자·더 넣을 말·가게 이름·주소·날짜는 **적은 그대로**. 인스타 화면이 덮는 위·아래는 비울 것.
- **그림 모델 (기본 `openai`, 2026-11-18 바꿈)**: **OpenAI 이미지 API**(`gpt-image-2`)를 `OPENAI_API_KEY`로 부릅니다.
  - 첨부 그림(로고, 메뉴 사진)이 있으면 `/v1/images/edits`에 `image[]`로 보내 참고하게 하고, 없으면 `/v1/images/generations`.
  - 품질·크기: `POSTER_OPENAI_QUALITY`(기본 `medium`), `POSTER_OPENAI_SIZE`(기본 `1024x1536`). 모델은 `POSTER_OPENAI_MODEL`.
  - **그림 한 장마다 요금**이 듭니다. 응답의 `usage`로 값을 셈해 서버 로그에 남깁니다 ("OpenAI 그림 … 약 $0.0xx").
  - 예전 방식 `codex`(ChatGPT 계정으로 로그인한 Codex CLI, 구독제)도 그대로 쓸 수 있습니다: `POSTER_IMAGE_ENGINE=codex`.
- 받은 그림은 **1080 × 1920** 으로 맞춥니다. 비율이 조금 다르면 같은 그림을 흐리게 깔고 가운데에 놓습니다.
- 한 번에 하나씩 그립니다. 결과는 `server/db/app_data/posters/<일감 id>.png` (git 에 올라가지 않음).

### 값 (gpt-image-2, 2026-11-18 OpenAI 문서 기준)
- 그림(출력): 1024×1536 한 장 low 약 $0.005, **medium 약 $0.041**, high 약 $0.165 (출력 토큰 1백만당 $30)
- 넣는 것(입력): 글 1백만 토큰당 $5, 그림 1백만 토큰당 $8. 참고 그림은 늘 고해상도로 읽어 그림 값의 대부분이 될 수 있습니다
- 실제 값은 로그의 usage 로 확인합니다

### 준비
1. `server/.env`: `OPENAI_API_KEY=sk-...` (`POSTER_IMAGE_ENGINE=openai` 가 기본값)
2. 확인: `GET /api/poster_ai/engine` → `{"engine": "openai", "ready": true, "note": "OpenAI gpt-image-2 (medium, 1024x1536)로 그려요"}`
- Codex 로 그릴 때: Codex CLI 설치 후 `codex login` → **Sign in with ChatGPT**, `POSTER_IMAGE_ENGINE=codex`. PATH 에 없으면 `CODEX_BIN=/전체/경로/codex`
- 시험할 때나 그림 없이 흐름만 볼 때: `POSTER_IMAGE_ENGINE=mock` (사진만 합친 그림, 글자 없음)

### 나중에 OpenAI API 로 옮길 때
`image_engine.generate` 하나만 바꾸면 됩니다. 이미지 편집 API(`/v1/images/edits`, 첨부 그림 여러 장)에 같은 프롬프트와 그림을 넘기면 됩니다. 화면과 나머지 서버 코드는 그대로입니다.

## 4. API
| | |
|---|---|
| `GET /api/poster_ai/engine` | 그림을 그릴 수 있는지 |
| `GET /api/poster_ai/suggest?plan_id=` | 상황, 문구 3개, 느낌 목록, 로고 있는지 |
| `POST /api/poster_ai/jobs` | 그리기 시작 `{"plan_id", "photos": [{"label", "url"}], "use_logo", "headline", "line", "extra", "style", "menu"}` (사진은 네이버 사진 주소나 data URL, 1~3장) |
| `GET /api/poster_ai/jobs/{id}` | `RUNNING` / `DONE` / `FAILED`(이유) |
| `GET /api/poster_ai/jobs/{id}/image` | 다 그린 PNG |

시험: `server/tests/modules/test_poster_ai.py` (OpenAI·Codex 는 가짜로 바꿔 실제로 부르지 않음)
