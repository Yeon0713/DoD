# 목업 v1 고정 데이터

분석 테스트의 손계산 기대값을 계산한 목업 CSV 다. 테스트는 `read_mock_csv(FIXTURE_DIR)` 로 이 폴더를 읽는다.

- 출처: 커밋 `d80e566` 의 `server/db/mock/out/*.csv` 10개를 내용 그대로 복사했다.
- 기간: 2026-08-17 ~ 2026-11-30 (매장 s001 한림국수 한 곳, 주문 8,368건, 날씨 106일, 경기 8, 행사 4)
- 고정한 이유: 기준선·특별한 칸·과거 효과·계절·데모 주 달력 기대값은 이 데이터의 `orders.csv`·`weather_daily.csv` 를 손으로 더해 확인한 값이다.
  목업은 그 뒤 1년치로 다시 만들어졌고(`db/mock/out/s001/`, `common/`), 다시 만들 때마다 값이 바뀐다.
  손계산 테스트가 목업 갱신에 따라 깨지지 않게 이 판을 따로 둔다.
- 이 폴더의 CSV 는 고치지 않는다. 새 데이터로 확인하려면 폴더를 새로 만들고 기대값을 다시 손계산한다.
- 앱이 쓰는 지금 데이터(DB)는 `tests/data_pipeline/` 의 테스트가 확인한다.
