# 화면 글 고치기 (ui-text)

앱 화면의 글(제목, 설명, 버튼, 띠, 시트, 오류 등)을 **화면별로 모아 보고, [수정] 칸에 적어 코드에 바로 넣는** 도구입니다.
코드를 열어 글을 하나씩 찾지 않아도 됩니다.

## 켜기

```bash
cd mobile && npm run ui-text
```

브라우저에서 http://localhost:8090 을 엽니다. (Claude 데스크톱 앱이면 `.claude/launch.json` 의 `ui-text`)

## 쓰는 법

1. 왼쪽에서 화면을 고릅니다. 화면 이름, 경로, **그 화면에서 할 수 있는 것**이 위에 나옵니다.
2. 줄마다 `종류(제목, 버튼, 설명, 띠, 시트 안 버튼 …) | 원본 | [수정]` 입니다. 제목이 맨 위, 그 다음 화면 본문 글, 그 다음 화면이 쓰는 부품의 글 순서입니다.
3. [수정] 칸에 바꿀 글을 적으면 바로 `mobile/scripts/ui-text/edits.json` 에 저장됩니다. 비워 두면 그대로 둡니다. 줄 바꿈은 화면의 줄 바꿈이 됩니다.
4. 다 적었으면 **코드에 넣기** → 바꿀 목록을 확인하고 **바꾸기**. 코드의 글이 바뀌고 타입 검사(tsc)를 돌려 결과를 보여 줍니다.
5. 넣은 수정은 edits.json 에서 빠지고, 화면을 다시 불러오면 **원본 칸이 수정본으로** 바뀌어 있습니다. 앱(8082)은 저절로 새로 고쳐집니다.

- 위 검색 칸: 모든 화면에서 글을 찾습니다.
- "이 화면이 같이 쓰는 글": 여러 화면이 함께 쓰는 글(카드 문구, 요일 이름, 오류 문구 등)은 따로 묶여 있습니다. 여기서 고치면 쓰는 화면 모두 바뀝니다.
- 보라색 `${…}` 는 코드가 채우는 자리(가게 이름, 시각 등)입니다. **순서 그대로 남겨야** 넣어집니다.
- "읽어 주기 이름"은 화면에 보이지 않고, 화면 읽기 기능이 읽는 글입니다.

## 페이지 없이 넣기

edits.json 을 직접 고친 뒤:

```bash
cd mobile && npm run ui-text:apply
```

## 어떻게 동작하나

- `scripts/ui-text/core.mjs` 가 `src/app`, `src/components`, `src/lib` 을 TypeScript 파서로 읽어 한글이 든 글을 모읍니다. 주석, import, 타입, 비교에 쓰는 문자열(`=== "점심"`, `startsWith("인사")`)은 뺍니다. `src/mocks`(목업 데이터)와 서버가 보내는 글은 대상이 아닙니다.
- 화면 경로 파일(`src/app/**`)에서 시작해 그 화면이 부르는 함수를 따라가 글을 화면별로 묶습니다. 개발 화면(`/dev`)은 개발 화면 파일 안에서만 따라갑니다.
- 화면 이름과 설명은 `scripts/ui-text/screens.json` 에 있습니다. 화면이 새로 생기면 여기에 한 줄 더하세요.
- 수정은 `파일 + 함수 + 원본 글` 로 찾아 넣습니다. 코드가 바뀌어 원본을 못 찾으면 넣지 않고 "원본을 못 찾은 수정"으로 남깁니다.
- 잘못 넣었으면 git 으로 되돌리면 됩니다 (`git diff`, `git checkout -- <파일>`).
