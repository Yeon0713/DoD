## 1. 무엇이 바뀌었나

| 앞 안 | 이번 안 |
|---|---|
| 브리핑, 인스타, 알바생이 각자 다른 줄 | 하루 시간 순서의 다섯 줄. 한 줄 안에서 세 기능이 이어짐 |
| 브리핑에 인스타와 알바생이 없음 | 브리핑 다섯 단계 안에 들어감: 아쉬운 리뷰 → 알바생 할 일, 좋은 리뷰 → 인스타 글. 일정은 단체 예약이 있다는 사실만 알림 (자리 배치·준비할 일은 도나가 정하거나 묻지 않음, 2026-11-16 결정) |
| 처음 쓰는 날이 없음 | 인스타 연결, 인스타 허용 화면, 메뉴 사진, 알바생 초대, 매일 하는 일 정하기 |
| 영업 중 장면이 적음 | 레시피 바꾸기, 전화 예약, 받는 사람 고쳐 말하기, 잠금 화면 알림 |
| 마감이 없음 | 오늘 정리(매출 한 줄 + 세 기능), 인스타 반응, 내일 미리 보기 |
| 틀렸을 때가 없음 | 없는 이름, 아직 안 들어온 알바생, 인스타 연결 끊김, 보낸 것 취소 |
| 알바생 앱이 글자 위주 | 메신저로 받은 글, 여섯 칸 코드, 입력 칸, 입장 완료, 홈 화면 추가와 알림, 잠금 화면, 자세히 보기 |
| 가상의 곱창집 | 초옹장 김호찬 사장님. 메뉴, 매출, 리뷰, 알바생 이름이 실제 목업 데이터. 메뉴·가게 사진은 네이버 플레이스에서 받아 넣음 |
| 알바생 할 일이 그때그때 시키는 것뿐 | **매뉴얼 + 오늘만.** 처음에 기본 매뉴얼(영업 준비, 영업 중, 마감)을 정하고, 그날 변수가 있을 때만 "오늘 더 할 것", "오늘 하지 말 것"을 말로 보냄 (2026-11-16 결정) |
| 아쉬운 리뷰에서 도나가 고칠 점을 권함 | **도나는 고칠 점을 권하지 않음.** 화면에는 실제로 단 답글을 보여 주고, 고치는 것은 사장님이 말로 정함 (2026-11-16 결정) |
| 알바생이 주방·홀을 고름, 사장님이 "홀 전원"에게 보냄 | **맡은 곳을 없앰.** 사장님은 "오늘 나온 사람 모두", "다섯 명 모두", 또는 이름("하린이한테")으로 보냄 (2026-11-16 결정) |

**디자인에서 고친 것**

| 무엇 | 고친 것 | 이유 |
|---|---|---|
| 아이콘 칸 색 | 초록, 파랑, 분홍을 모두 연한 갈색 한 가지로 | 색이 뜻 없이 많았음 (일정 탭에서 받은 지적과 같은 문제). 진한 칸은 "지금 사장님이 봐야 하는 줄" 하나에만 |
| 상태 표시줄 | 장면의 실제 시각 (9:01, 6:10 …) | 하루의 어느 때인지 화면만 보고 알게 |
| 인스타 미리 보기 | 계정 줄(초옹장 로고), 세로 4:5 사진, 1/4, 반응 아이콘, 한 줄 글 "… 더 보기". 1/4가 있어 넉 장 점은 뺌 | 사장님이 매일 보는 인스타 게시물 모양 그대로. 피드에서 가장 많이 쓰는 세로 4:5로 |
| 사진 | 초옹장이 네이버 플레이스에 올린 메뉴 사진 | 메인 서버의 가게 불러오기가 읽어 둔 주소에서 받음 (7장) |
| 알바생 앱 입력 | 테두리 있는 입력 칸, 지금 쓰는 칸은 진한 테두리 | 앞 안은 글자만 있어 누를 곳이 안 보였음 |
| 알바생 할 일 | 네모 체크, 확인 필요는 맨 위 따로, 새로 온 줄은 "방금"을 진하게 | 휴대폰 미리 알림, 카카오톡 할 일과 같은 모양 |

## 3. 알바생 앱 (F)

알바생이 자기 휴대폰에서 씁니다. 앱 스토어에서 깔지 않고 사장님이 보낸 주소로 열고, 홈 화면에 추가해 앱처럼 씁니다. 말은 기능 이름만 씁니다. 도나 캐릭터와 듣기 알약이 없고, 알바생은 말로 쓰지 않습니다. 화면의 주인은 저녁 근무 문하린입니다. 할 일 줄 아래에 "매뉴얼"인지 "오늘만"인지 적습니다.

| 화면 | 알바생이 하는 것 | 사장님 쪽과 만나는 곳 |
|---|---|---|
| F-01 사장님이 보낸 글 받기 | 메신저에서 주소를 누름 | D-04에서 사장님이 보낸 글 |
| F-02 초대 코드 | 여섯 칸에 코드를 넣음 (복사하면 한 번에) | 사장님이 끊은 코드는 안 됨 |
| F-03 가입 | 이름(하린), 아이디, 비밀번호 | 이름이 "하린이한테"의 그 이름 |
| F-04 입장 완료 | "초옹장 · 문하린"을 확인하고 "시작" | "시작"을 누르면 D-05 알림. 맡은 곳(주방·홀)은 고르지 않음 |
| F-05 홈 화면에 추가와 알림 | 홈 화면에 추가하고 알림 허용 | 문자·알림톡이 아니라 휴대폰 자체 알림 |
| F-06 할 일 (오후 3시 출근) | 오늘 할 일을 봄 | D-06 매뉴얼과 사장님이 오늘만 보낸 것이 이미 와 있음 |
| F-07 잠금 화면 알림 | 알림을 눌러 할 일을 엶 | D-21 스토리 손님 서비스, D-19 메밀 알레르기 확인 필요 (매뉴얼) |
