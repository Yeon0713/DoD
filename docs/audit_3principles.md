# 3원칙 점검: 사람들이 쓰지 않는 앱의 공통점 (2026-11-11)

점검 대상: `mobile/` 앱 (브랜치 `jheroorehj/feat-frontend`, 커밋 `8769051`).
방법: 웹 미리 보기(375×812)에서 마우스로 직접 눌러 봤다. 처음 쓰는 날(시작 → 가게 찾기 → 네이버 → 확인 → 알림 시간 → 알림 켜기 → 홈), 발표 시나리오 화요일 할 일 5개, 매출, 이번 주, 설정, 끝낸 일 다시 보기를 지났다.

| 원칙 | 판정 | 한 줄 |
|---|---|---|
| 1. 처음 할 행동을 먼저 안내 | 부분 통과 | 매일 쓰는 홈은 "지금 할 일 1개, 지금 하기"로 분명하다. 하지만 처음 쓰는 날은 설정 5단계를 거쳐야 첫 행동(답글 달기)에 닿고, 첫 답글 안내 카드는 다른 할 일이 있으면 아예 나오지 않는다. |
| 2. 한 화면에 핵심 기능 하나 | 대체로 통과 | 지금 할 일, 답글, 점검, 메뉴판, 포스터 화면은 한 화면 한 가지다. 홈(07)은 목록 3개, 매출 첫 화면은 그래프 2개와 링크 4개로 한 화면에 여러 가지가 있다. |
| 3. 우리 앱을 써야 할 이유 | 부분 통과 | 배달앱 리뷰를 한곳에, 날씨·경기·축제를 메뉴판과 포스터로 바로 잇는 점은 다른 앱에 없다. 하지만 화면이 그 이유를 말하지 않는다. "도나가 무엇을 덜어 줬는지"가 일주일 뒤 결과 알림에만 있다. |

## 1. 처음 할 행동을 먼저 안내하는가

DONNA의 첫 행동은 **"도나가 써 둔 답글을 처음으로 올려 보기"**다. 가게를 찾자마자 "리뷰 10개를 함께 찾았어요"가 나오므로, 답글을 달아 본 순간이 도나를 쓸 이유를 처음 느끼는 때다.

### 잘 된 것
- 매일 쓰는 홈: 맨 위에 "오늘 할 일이 N개 남았어요", 그 아래 "지금 할 일" 카드 1장과 "지금 하기" 버튼. 무엇부터 할지 고민할 필요가 없다.
- 지금 할 일 화면: 카드 1장, 도나가 써 둔 답글, 버튼 1개("이대로 답글 달기"). 버튼은 화면이 작아도 아래에 고정된다.
- 알림 시간은 장사 시간에 맞춰 도나가 골라 두고, 사장님은 "이대로 좋아요"만 누르면 된다.

### 문제
| # | 심각도 | 무엇 | 근거 |
|---|---|---|---|
| 1-1 | 높음 | **첫 답글까지 설정 5단계.** 시작 → 가게 찾기 → 네이버 연결 → 불러온 정보 확인 → 알림 시간 → 알림 켜기를 지나야 홈에 닿는다. 그사이 사장님이 직접 해 보는 것은 없다. | 처음 쓰는 날 화면 6장, 진행 막대 5칸 |
| 1-2 | 높음 | **첫 답글 안내 카드(06-4f)가 거의 나오지 않는다.** "답글 없는 지난 리뷰 N개를 찾았어요" 카드는 다른 할 일이 하나도 없을 때만 나온다 (`lib/todayCards.ts` 71행). 처음 쓰는 날 다른 카드가 있으면 첫 행동 안내가 사라진다. | 처음 설정을 마치고 들어온 홈에 할 일 4개가 바로 나왔고 첫날 카드는 없었다 |
| 1-3 | 중간 | **시작 화면이 기능 소개다.** "답글을 써 둬요, 축제·경기·날씨를 미리 알려요, 다시 온 손님 수까지 알려요" 세 줄은 기능 목록이다. 처음 할 행동("우리 가게를 찾으면 답글 안 단 리뷰를 바로 보여 드려요")을 말하지 않는다. | 06-1 화면 |
| 1-4 | 중간 | **네이버 연결을 두 번 묻는다.** 처음 쓰는 날에 한 번, 메뉴판 카드에서 또 한 번 묻는다. 처음 쓰는 날에는 아직 필요 없는 일이다. | 06-2n, 06-50 |

### 고칠 방향 (Figma 먼저)
- **처음 쓰는 날을 "가게 찾기 → 첫 답글 → 알림 켜기"로 줄인다.** 가게를 찾으면 바로 "답글 안 단 리뷰 N개, 도나가 써 뒀어요"를 보여 주고 하나를 올리게 한다. 네이버 연결은 메뉴판 카드가 처음 올 때 묻는다 (지금도 그 흐름은 있다). 알림 시간은 기본값으로 두고 설정에서 바꾸게 한다. 알림 켜기는 첫 답글을 올린 직후, "다음 리뷰도 이렇게 알려 드릴까요?"로 묻는다.
- **첫날 카드는 할 일이 있어도 맨 앞에 둔다.** 처음 답글을 올리기 전까지는 "지금 할 일" 자리에 첫날 카드를 보여 준다. 코드는 `buildTodayCards`의 조건 하나라 작다.
- **시작 화면은 약속 한 줄과 버튼 하나로.** "가게만 찾으면, 답글 안 단 리뷰부터 도나가 챙겨요"처럼 첫 행동을 말한다.

## 2. 한 화면에 핵심 기능 하나인가

| 화면 | 핵심 기능 | 판정 | 메모 |
|---|---|---|---|
| 홈 (07) | 지금 할 일 시작 | 주의 | "지금 할 일" 카드, "다음 할 일" 목록, "오늘 끝낸 일" 목록 세 덩어리. 할 일이 5개면 한 화면 반, 끝낸 일까지 쌓이면 두 화면이다. 맨 위 카드가 가장 크고 버튼이 하나라 길은 잃지 않는다. |
| 지금 할 일 (07-3) | 카드 하나 처리 | 통과 | 카드 1장, 버튼 2개(주 버튼 1개) |
| 답글 고쳐 쓰기 | 답글 고치기 | 통과 | |
| 리뷰 점검 | 반복 불만 확인 | 통과 | "다른 가게는 이렇게" 는 접어 둠 |
| 메뉴판 순서, 네이버 | 순서 바꾸기 | 통과 | 화면이 여러 장이지만 장마다 한 가지 |
| 포스터 | 포스터 올리기 | 통과 | 사진 고르기, 미리 보기, 올릴 곳을 장마다 나눔 |
| 이번 주 | 이번 주 손님 예보 | 통과 | 요일 하나를 고르면 그날만 보여 줌 |
| 매출 첫 화면 | 오늘 얼마 팔았나 | 주의 | 오늘 매출 카드(숫자, 비교, 진행 막대, 주문 수, 객단가, 시간별 그래프)와 이번 주 카드(요일별 그래프, 합계 2개)가 함께 있고, 아래에 링크 4개. 두 화면 가까이 내려야 끝난다. |
| 설정 | 가게 정보 고치기 | 통과 | 목록 6줄 |

### 문제
| # | 심각도 | 무엇 |
|---|---|---|
| 2-1 | 중간 | **홈의 "오늘 끝낸 일"이 길어진다.** 다 끝낸 뒤 다시 보려는 목적(07 요청)은 맞지만, 할 일이 남아 있을 때도 끝낸 목록이 펼쳐져 있어 홈이 길어진다. |
| 2-2 | 중간 | **매출 첫 화면에 숫자가 많다.** 오늘 카드 하나에 숫자 6개와 그래프 하나, 이번 주 카드에 그래프 하나와 숫자 3개. 사장님이 매일 볼 숫자는 "오늘 얼마, 평소보다 많나 적나" 하나다. |
| 2-3 | 낮음 | **알림 꺼짐 띠가 홈 맨 위를 차지한다.** 처음 쓰는 날 "나중에 켤게요"를 고르면 홈 맨 위에 빨간 띠가 늘 있어 "지금 할 일"보다 먼저 눈에 들어온다. |

### 고칠 방향 (Figma 먼저)
- 홈: 할 일이 남아 있으면 "오늘 끝낸 일 N개" 한 줄만 보이고 누르면 펼친다. 다 끝냈을 때(07-2)만 목록을 펼쳐 둔다.
- 매출 첫 화면: "오늘 606,500원, 어제 이 시간보다 3% 많아요" 한 덩어리만 크게. 시간별 그래프와 이번 주 그래프는 "자세히"로 보낸다.
- 알림 꺼짐 띠: 홈 맨 아래나 할 일을 하나 끝낸 뒤("다음 리뷰도 알려 드릴까요?")로 옮긴다.

## 3. 지금 쓰는 앱 대신 도나를 써야 할 이유

사장님이 이미 쓰는 것: 배민·쿠팡이츠·요기요 사장님 앱(리뷰 답글, 매출), 네이버 스마트플레이스(메뉴, 리뷰), 인스타그램, 포스기 매출.

### 도나만 하는 것 (지금 앱에 있음)
| 번거로운 일 | 지금 쓰는 앱에서 | 도나에서 |
|---|---|---|
| 배달앱마다 리뷰 확인하고 답글 쓰기 | 앱 4개를 돌며 하나씩 직접 쓴다 | 한 화면에 모이고 답글이 써져 있다. 누르기만 한다. |
| 같은 불만이 반복되는지 알아채기 | 리뷰를 하나씩 읽어서는 모른다 | "일주일에 3번, 모두 저녁 7시쯤"까지 이어서 보여 준다 |
| 날씨·경기·축제에 맞춰 메뉴판 바꾸기 | 일정을 직접 챙기고 스마트플레이스에서 직접 바꾼다 | 전날 알려 주고, 누르면 네이버 메뉴 순서를 바꿔 둔다 |
| 홍보 포스터 만들기 | 디자인 앱이나 업체를 쓴다 | 경기·축제 문구와 메뉴 사진으로 만들어 둔다 |
| 단골에게 다시 오게 하기 | 누가 단골인지 따로 본다 | 주문 주기로 찾아서, 다음 주문 전에 답글이 올라가게 맡긴다 |
| 한 일이 효과가 있었는지 | 알 방법이 없다 | 일주일 뒤 "재주문 2분", "배달 지연 리뷰 3건 → 0건" |

### 문제
| # | 심각도 | 무엇 |
|---|---|---|
| 3-1 | 높음 | **화면이 이 이유를 말하지 않는다.** 카드는 "배달이 늦었다는 리뷰예요"처럼 할 일만 말한다. 배민, 쿠팡이츠, 요기요, 네이버 리뷰를 한곳에서 챙긴다는 점이 홈에 드러나지 않는다 (플랫폼은 카드를 열어야 작은 글씨로 보인다). |
| 3-2 | 높음 | **도나가 덜어 준 것이 바로 보이지 않는다.** 다 끝낸 홈(07-2)은 "수고하셨어요"뿐이다. 효과는 일주일 뒤 결과 알림 2장에만 있다. 매일 "오늘 도나 덕분에 무엇을 했는지(답글 3개, 메뉴판 1번, 포스터 1장)"가 보이면 다음 날도 열 이유가 된다. |
| 3-3 | 중간 | **"왜 지금"인지가 일부 카드에만 있다.** 메뉴판 카드는 "내일부터 추워져요", 단골 카드는 "내일 주문 전에"가 있어 좋다. 포스터 실행 카드("포스터 올릴 시간이에요")와 좋은 리뷰 묶음 카드는 왜 지금인지가 약하다. |
| 3-4 | 낮음 | **목업 이음새.** 개발 화면에서 다른 매장(예: 치킨호프)을 고른 뒤 처음 쓰는 날을 지나면, 네이버에서 불러온 메뉴가 "잔치국수, 비빔국수"로 나온다. 처음 설정에서 바꾼 알림 시각(10:30, 15:30, 20:30)이 매장 시나리오에도 남아 카드 시각이 바뀐다. 발표 전에는 개발 화면 "처음부터 다시"로 지우고 시작하면 된다. |

### 고칠 방향 (Figma 먼저)
- 다 끝낸 홈에 **"오늘 도나가 덜어 준 일"** 한 줄: "답글 3개, 메뉴판 1번, 포스터 1장. 직접 했으면 40분쯤 걸렸어요." 끝낸 일 기록(`dona.cardState.v1`의 `note`)으로 바로 셀 수 있다.
- 홈 "지금 할 일" 카드에 **어디서 온 일인지** 작은 줄을 넣는다: "배달의민족 리뷰", "네이버 메뉴판", "인스타". 여러 앱을 돌지 않아도 된다는 것이 보인다.
- 카드마다 **"왜 지금"** 한 줄을 붙인다: "목요일 경기 3일 전이에요", "토요일 주문 전에 올려야 손님이 봐요".
